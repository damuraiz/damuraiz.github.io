# Damuraiz — Оболочка

Статический сайт альбома для [damuraiz.com](https://damuraiz.com/).
Главная страница содержит четыре трека в порядке официального релиза:
«Новая нефть», «Награда за верность», «Я умер в двадцать втором», «До завтра».
Страница сингла сохранена по адресу `/new-oil/`.

## Публикация

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
После слияния PR альбом заменит главную страницу. Сборка и сервер не нужны:
HTML, CSS, JavaScript и аудио обслуживаются напрямую GitHub Pages.
`.nojekyll`, `CNAME` с доменом `damuraiz.com` и существующая Google Analytics
`G-4GMCCWMFBV` сохранены. Настройки DNS и хостинга менять не требуется.

## Плеер и тексты

Один audio-элемент переключает треки без наложения звука. После окончания
песни начинается следующая; после четвёртой воспроизведение останавливается.
Повтор альбома можно включить явно. Есть пауза, предыдущий/следующий трек,
перемотка, громкость, скачивание MP3, управление с клавиатуры и Media Session.
При прокрутке появляется компактный плеер. Адрес `/?track=twenty-two`
выбирает конкретный трек без автоматического воспроизведения.

Выбор трека меняет сцену, акцентный цвет, цитату и текущий текст. Кнопки
в разделе текстов позволяют читать любую песню, не прерывая музыку.
Слова и строфы сохранены из исходников; инструкции для Suno и английские
пометки исполнения исключены, названия разделов переведены на русский.
Полные тексты есть в HTML и в скачиваемых TXT. Без JavaScript доступны
все тексты, ссылки скачивания и четыре обычных браузерных аудиоплеера.

## Материалы

Исходники: Google Drive → Plague → Оболочка → Music / Lyrics / Photos.
Четыре новые широкие сцены созданы по обложкам песен, лирике и персонажу
из Character 2; это отдельные изображения без текста обложек. Сцена
«Я умер в двадцать втором» уточнена по дополнительному портрету автора:
перед стеклом — персонаж в полевой куртке, в отражении — молодой образ
в белой рубашке с распущенной синей бабочкой. Сцены и обложка оптимизированы
в WebP (вместе менее 1 МБ). Оригинальные MP3 сохранены без перекодирования;
«Новая нефть» повторно использует существующий `assets/new-oil.mp3`.
Остальные MP3 и чистые TXT лежат в `assets/obolochka/`.

Шрифт DejaVu: лицензия `assets/display-license.txt`.
Права на музыку, тексты и изображения остаются у автора; публичный
репозиторий не предоставляет отдельную лицензию на их использование.

## Ссылки

Ссылка на весь Spotify-альбом и отдельные ссылки на треки подтверждены
по официальным страницам Spotify. Ссылка на YouTube-плейлист предоставлена
автором. Общие ссылки находятся в `album-links.js`; данные треков —
в `album-data.js`. TikTok и Instagram исключены по просьбе автора.

## Проверка и локальный просмотр

Для просмотра: `python -m http.server 8000`, затем http://localhost:8000/.
Для проверки: `npm install`, `npx playwright install chromium`, `npm test`.
Тест сам запускает локальный HTTP-сервер с поддержкой Range и проверяет
реальное воспроизведение всех четырёх MP3, перемотку, последовательность,
повтор, перезапуск, быстрое переключение, независимое чтение текстов,
компактный плеер, прямые ссылки, ширины 320/390/768/1440 px, страницу сингла
и вариант без JavaScript. Скриншоты для ревью: `docs/preview/`.
