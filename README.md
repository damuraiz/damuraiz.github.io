# Damuraiz — Новая нефть

Статический сайт релиза: https://damuraiz.github.io/

## Публикация

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
Сборка и сервер не нужны. Файл `.nojekyll` отключает Jekyll.
Для обновления сайта измените файлы в main; Pages опубликует их автоматически.
Cloudflare Worker не используется: GitHub Pages обслуживает аудиофайлы напрямую.

## Материалы

Полный текст, оригинальные MP3 и M4A, Spotify / YouTube, две новые сцены
по исходным ассетам Plague. Аудиофайлы сохранены без перекодирования.
Шрифт DejaVu: лицензия assets/display-license.txt.
Права на музыку, текст и изображения остаются у автора;
публичный репозиторий не предоставляет отдельную лицензию на их использование.

## Домен

В настройках Pages пользователь указал damuraiz.com; файл CNAME сохраняет эту привязку.
Регистратора GoDaddy менять не требуется. DNS должен указывать на GitHub Pages.
Не включайте проксирование Cloudflare для этого сайта.
Тестовый адрес github.io перенаправляется на указанный собственный домен.
